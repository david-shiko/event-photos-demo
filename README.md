# Вечер — демо для фотографов

Кликабельный макет сервиса фото с мероприятия: гость открывает ссылку в чате, находит свои кадры
по времени и забирает их. Логики нет — данные мок, фотографии настоящие (Unsplash, CC0).

## Стек

Next.js 16 (App Router) + TypeScript, статический экспорт (`output: 'export'`), без бэкенда.
Стили — обычный CSS, дизайн-токены в `app/globals.css`, `app/event.css`, `app/map.css`.
Карта — MapLibre GL, тайлы и стиль с OpenFreeMap (бесплатно, без ключа). Воркер MapLibre лежит
в `public/maplibre-gl-worker.mjs`: без него карта не стартует в статической сборке.

## Локально

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # статическая сборка в out/
```

## Деплой

Пуш в `main` запускает GitHub Actions: сборка с `NEXT_PUBLIC_BASE_PATH=/<имя-репозитория>`
и выкладка в GitHub Pages. Для репозитория вида `user.github.io` переменную не задавать.

## Что здесь мок

- Вечер «Свадьба Ани», 168 кадров, 24 источника, 30 вечеров на карте, 27 из них в один вечер 11 июля, плюс скрытый черновик кабинета, 3 вечера в кабинете.
- Фотографии — настоящие, Unsplash (CC0), лежат в `public/img`; авторы — в
  `../design/img/real/CREDITS.md`.
- Карта настоящая: тайлы тянутся из сети, адреса и подписи улиц реальные. Координаты вечеров —
  выдуманные точки вокруг центра Москвы.
- Вечер делится на двухчасовые чипсы 19:00–21:00, 21:00–23:00, 23:00–01:00, 01:00–02:00.
- Карточка вечера висит над пином, в панели её нет. Она живёт в слое маркеров карты, поэтому
  едет вместе с пином, а не догоняет его. Кнопок на ней нет: второй тап по карточке открывает вечер,
  тап по пустому месту карты её закрывает. При выборе пин не меняет размер — только обводку.
- Пять вечеров в одном адресе («Флакон») — стопка со счётчиком; две и больше в одном пятне тоже
  стопка, иначе соседний вечер был бы спрятан за чужим пином. Стопка того же размера, что пин.
- Пин 48 px на общем плане города и 78 px на близком: по прежним 38 промахивались пальцем.
- Длинное нажатие по карте (600 мс) открывает «Новый вечер здесь»: адрес ближайшего ориентира и
  координаты точки, под кнопкой ничего нет. Вечер создаётся в точке пальца, даже если рядом чужой
  вечер. Сдвиг больше 10 px отменяет; второй палец (пинч), кнопка зума, пин и карточка под пальцем
  жест не запускают. Кольцо удержания появляется через 160 мс, поэтому короткий тап не рисует
  ни точки, ни вспышки.
- Лист создания закрывается пальцем вниз или тапом по затемнению, кнопки «Отмена» нет.
  Действие в листе одно — «Создать вечер здесь».
- Форма вечера: назад ведёт туда, откуда пришли (из карты — на карту). Настройки — радиокнопки
  «кто видит» (по умолчанию только по ссылке) и «сколько храним» (90 дней), тумблеры: гости
  заливают, видео, оригиналы, вход по коду. Выбор видно на шаге оплаты.
- Длинное нажатие по кадру (450 мс) включает выбор: кнопки «Выбрать» в панели нет.
- «Найти себя» появляется только после того, как гость сам залил кадр: время берётся из EXIF,
  а не выдумывается. Кнопка живёт в localStorage рядом с загрузкой.
- Демо-переключатель экранов — только на карте (кнопка «☰ Экраны» под шапкой); на остальных
  экранах он бы лежал поверх кадров и кнопок.
- Лента суток: центр закреплён, шаг 5 минут, точки — начала вечеров. Пин живёт по времени:
  бледнеет за 30 минут до начала, исчезает через 30 минут после конца.
- 10, 13, 15 и 16 июля пустые намеренно — на них видно пустое время, а не пустой экран.
- Загрузка файлов имитируется таймером: настоящие файлы не читаются.
- Оплата имитируется: шаг «Оплатить» ждёт 1,5 с и не ходит ни в какой платёжный сервис.
  Созданный вечер остаётся в браузере (localStorage) и появляется в кабинете.
- Вход, доступ по коду и модерация не сделаны.
- «Скачать CSV» в отчёте отдаёт настоящий файл с теми же числами, что на экране.

## Проверки

```
npm run build   # out/
npm run qa      # играет собранный сайт мышью, пальцем и клавиатурой
QA_BASE=https://david-shiko.github.io/event-photos-demo/ npm run qa   # тот же прогон по живому сайту
QA_MAP=stub npm run qa          # механика без чужого тайл-сервера: плоский фон
QA_MAP=file QA_STYLE=/tmp/positron.json npm run qa   # подложка из локального файла стиля
QA_ONLY=пинч npm run qa         # только проверки, в чьём названии есть подстрока
```

Тайлы карты приходят с чужого сервера. Когда он недоступен, прогон идёт с подменой стиля
(`qa/mapstub.mjs`): на боевом сайте подмена не включается, без `QA_MAP` проверки ходят в сеть.

`qa/` поднимает статику из `out/` на свободном порту, открывает её в системном Chrome
(`CHROME_PATH`, иначе `/usr/bin/google-chrome`) и проверяет 49 сценариев: драг ленты мышью,
свайп пальцем, выбор дня, точки вечеров, пустое время, клавиатуру, клик по пину, чипсы вечера,
«Найти себя», Esc, пустой вечер, 404, адрес созданного вечера, сходимость цифр, имена плитки,
оплату, загрузку, шапку вечера, счётчики категорий, выбор длинным нажатием, точку создания
на карте, размер пинов и стопки, пинч двумя пальцами, удержание на пине и на кнопке зума,
приклеенную к пину карточку, закрытие карточки тапом, свайп листа создания вниз, адрес и
координаты в листе, короткий тап без кольца, неизменный размер пина при выборе, чётные размеры
пинов, возврат из формы на карту и наличие настроек. Доказательством считается только настоящее событие ввода — `element.click()`
и присвоение `scrollLeft` из кода не считаются. Красный прогон в CI блокирует деплой.
