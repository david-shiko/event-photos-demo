# Вечер — демо для фотографов

Кликабельный макет сервиса фото с мероприятия: гость открывает ссылку в чате, видит кадры
вечера и добавляет свои. Логики нет — данные мок, фотографии заглушки.

## Экраны

| Адрес | Экран |
|---|---|
| `/` | Карта вечера: пины, фильтры, карточка вечера, ссылка и QR |
| `/e/7kd2qf9xm/` | Страница вечера: обложка, вкладки, периоды, сетка, лайтбокс, выбор кадров |
| `/u/` | Загрузка: выбор файлов, прогресс, фон |
| `/photographer/` | Кабинет фотографа: вечера, просмотры, скачивания, отчёт, 690 ₽ |
| `/new/` | Новый вечер: четыре поля, оплата 690 ₽, ссылка и QR |

## Стек

Next.js 16 (App Router) + TypeScript, статический экспорт (`output: 'export'`), без бэкенда.
Стили — обычный CSS, дизайн-токены в `app/globals.css` и `app/event.css`.

## Локально

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # статическая сборка в out/
```

## Деплой

Пуш в `main` запускает GitHub Actions: сборка с `NEXT_PUBLIC_BASE_PATH=/<имя-репозитория>`
и выкладка в GitHub Pages. Для репозитория вида `user.github.io` переменную не задавать.

## Что здесь мок

- Вечер «Свадьба Ани», 168 кадров, 24 источника, 6 вечеров на карте, 3 вечера в кабинете.
- Фотографии — сгенерированные заглушки из `public/img`.
- Загрузка файлов имитируется таймером: настоящие файлы не читаются.
- Оплата имитируется: шаг «Оплатить» ждёт 1,5 с и не ходит ни в какой платёжный сервис.
  Созданный вечер остаётся в браузере (localStorage) и появляется в кабинете.
- Вход, доступ по коду и модерация не сделаны.
- «Скачать CSV» в отчёте отдаёт настоящий файл с теми же числами, что на экране.
